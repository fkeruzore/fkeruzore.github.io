**Github:** [fkeruzore/pylira](https://github.com/fkeruzore/pylira)

`pylira` is a lightweight Python wrapper around [LIRA](https://ui.adsabs.harvard.edu/abs/2016MNRAS.455.2149S/abstract) (LInear Regression in Astronomy), an R library implementing Bayesian linear regression via Gibbs sampling.

It exposes LIRA's regression routines to Python workflows without requiring users to write R directly, handling the data conversion and call bridging between the two languages.
